# Task 1 mask specification

The R1/R2/R3 target masks are generated by a deterministic hash, not by a mask
file. This page is the normative definition; the reference implementation is
`stable_mask()` in `src/baseline_task1_historical_mean.py`.

## Definition

A released mainline cell is a Task 1 target for regime `r` if and only if:

```text
is_score_eligible == True
AND hash64(panel|r|date|timestamp|link_id) / 2^64 < rate(r)
```

where:

- `hash64(s)` is the big-endian integer value of `blake2b(s, digest_size=8)`
  over the UTF-8 encoding of `s`;
- the five fields are joined with the literal `|` character;
- `rate(R1) = 0.20`, `rate(R2) = 0.30`, `rate(R3) = 0.50`;
- `panel` is the directional panel ID (for example `D7_I10_E`);
- `date` and `timestamp` are the **exact text values from the released
  parquet files**, converted with `astype(str)` and no reformatting;
- `link_id` is the released link ID as text.

Reference implementation:

```python
import hashlib

def is_masked(panel: str, regime: str, date: str, timestamp: str, link_id: str) -> bool:
    rate = {"R1": 0.20, "R2": 0.30, "R3": 0.50}[regime]
    key = f"{panel}|{regime}|{date}|{timestamp}|{link_id}".encode("utf-8")
    h = int.from_bytes(hashlib.blake2b(key, digest_size=8).digest(), "big")
    return h / 2**64 < rate
```

## Two traps to avoid

1. **Do not reformat the timestamp before hashing.** The hash uses the raw
   timestamp string exactly as stored in the released parquet. Parsing it to a
   datetime and re-serializing it (different timezone suffix, different
   precision) silently produces a *different, wrong* mask with no error.
   Convert to datetime only after computing the mask.
2. **`station_id` is not part of the hash.** The mask is drawn at the
   `(date, timestamp, link_id)` level, so when several detector stations share
   one link, they are always masked together at the same timestamp. The
   submission key still requires `station_id`, because predictions are scored
   per station.

## Properties

- The three regime masks are **independent draws**, so the R1, R2, and R3
  target sets overlap; a cell can be a target in more than one regime.
- The masks are identical for every participant and every rerun; no mask file
  is distributed because none is needed.
- Only cells with `is_score_eligible == True` are scored, whether masked or
  not; ineligible masked cells are excluded from RMSE.

## Required submission coverage

For each panel and regime, the required rows are exactly the eligible masked
cells of the public validation split, keyed by
`(panel, timestamp, station_id, link_id, mask_regime)`. Missing rows are
scored as a zero prediction (they are counted in the RMSE denominator), so
partial submissions are valid but self-penalizing.
